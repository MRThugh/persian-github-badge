# 🟦 Persian GitHub Badge

یک **نشان (Badge) گیت‌هاب با الهام از فرهنگ و هنر ایرانی**  
ترکیبی از رنگ‌های پرچم ایران، نقوش سنتی، تذهیب طلایی و Octocat گیت‌هاب.

این نشان برای **توسعه‌دهندگان ایرانی** طراحی شده که دوست دارند هویت فرهنگی خودشان را به شکلی مدرن و مینیمال نمایش دهند.

---

## ✨ ویژگی‌ها

- 🇮🇷 الهام‌گرفته از پرچم ایران  
- 🐙 استفاده خلاقانه از Octocat گیت‌هاب  
- ✨ تذهیب و هاله طلایی به سبک هنر ایرانی  
- 🎨 گرادیانت‌های مدرن (لاجوردی، فیروزه‌ای، طلایی)  
- 🧩 طراحی کاملاً SVG (برداری، سبک، قابل ویرایش)  
- ⚡ انیمیشن‌های ظریف و نرم

## 📦 استفاده

می‌توانید این نشان را در:

- README پروژه‌ها
- پروفایل GitHub
- وب‌سایت شخصی
- پورتفولیو

استفاده کنید.

### مثال استفاده در README:

```html
<img src="badge.svg" alt="Persian GitHub Badge" />
```

---

## 🛠️ شخصی‌سازی

می‌توانید به‌راحتی موارد زیر را تغییر دهید:

- نام (`Your Name`)
- عنوان (`PERSIAN DEVELOPER`)
- رنگ‌ها و گرادیانت‌ها
- اندازه (با تغییر `width` و `height`)

فایل SVG کاملاً خوانا و تمیز نوشته شده است.
